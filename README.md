# defi-legal

Les pages publiques de l'application **Défi** (Kanea consulting SRL).

- `index.html` — politique de confidentialité, publiée via GitHub Pages.

Ce dépôt ne contient **que** le site public. Le code de l'application vit
ailleurs, dans un dépôt local séparé (`~/Desktop/Defi`), et n'est pas publié.

## Mettre la page à jour

1. Modifier `index.html` (penser à la date de « Dernière mise à jour »).
2. `git add -A && git commit -m "…" && git push`
3. GitHub Pages republie tout seul, en une minute environ.
